10. Diagrama de Componentes

El diagrama de componentes UML muestra la arquitectura del sistema dividida en módulos de software con sus dependencias e interfaces. Para el SIA-NP se utiliza una arquitectura de 3 capas.

Arquitectura de 3 Capas

(fetch, puerto 3001)

(mssql, puerto 1433)

Diagrama

Componentes por Capa

Capa de Presentación (React)

  • Navegador Web: Chrome, Firefox, Edge — cliente HTTP
  • SIA-NP Web: aplicación SPA (Single Page Application)
    • Páginas: login, movimientos, órdenes, recepción, inventario
    • Componentes: elementos reutilizables de la UI
    • api.js: cliente HTTP para la API REST
    • sesion.jsx: contexto React para JWT y sesión

Capa de Lógica de Negocio (Express)

  • API REST: servidor Express en puerto 3001
    • Rutas: /productos, /movimientos, /ordenes, /recepcion
    • Controladores: lógica de cada CU (movimientos.js, ordenes.js, etc.)
    • Entidades: modelos de dominio (Producto.js, Movimiento.js)
    • Autenticación: auth.js con JWT y bcrypt
    • Conexión BD: db.js con pool de conexiones mssql

Capa de Datos (SQL Server)

  • SQL Server 2022: motor de BD en Docker (puerto 1433)
    • SIA_NP: 14 tablas, 3 vistas, 2 stored procedures
  • Scripts SQL: 01_creacion, 02_datos_prueba, 04_ajustes_app
  • Docker: docker-compose.yml, init-docker.sh

Interfaces

Notación UML 2.x

  • Componente: rectángulo con estereotipo «component» e icono (dos rectángulos pequeños)
  • Subsistema: paquete con estereotipo «subsystem» que agrupa componentes
  • Interfaz proporcionada: círculo (lollipop) conectado al componente
  • Dependencia: flecha punteada del componente que depende hacia el que provee
Relación con el PPTX: Este diagrama sigue el material del Tema 3 "Arquitectura de Software" de la materia, mostrando componentes reales de software (React, Express, SQL Server), no solo componentes lógicos del dominio. Es similar a los ejemplos de "tienda en línea" y "cajero" del PPTX.
