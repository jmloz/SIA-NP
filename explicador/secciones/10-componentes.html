Notación UML 2.x

  • «component»: rectángulo con icono de componente (dos rectángulos pequeños)
  • «device»: caja amarilla que representa hardware físico
  • «subsystem»: paquete que agrupa componentes de software
  • «executionEnvironment»: infraestructura donde se ejecutan componentes
  • Interfaz proporcionada: círculo (lollipop) conectado al componente
Relación con el PPTX: Este diagrama sigue el material del Tema 3 "Arquitectura de Software", mostrando tanto componentes de software (React, Express, SQL Server) como de hardware (PC, servidores, impresora, red), similar a los ejemplos del PPTX.
